# CC-002: Shadow Testing — Modelo Control y Modelo Tratamiento

**CC-ID:** CC-002
**Fecha:** 2026-04-28
**Estado:** APROBADO y EJECUTADO
**Aprobado por:** jdrodriguez1000 (Product Owner)
**Agente ejecutor:** ai-business-strategist

## Cambio

Incorporacion de Shadow Testing como capacidad de primera clase en el sistema Flores_CD. El sistema ejecuta simultaneamente un modelo control (prediccion visible al analista) y un modelo tratamiento (prediccion en sombra para comparacion offline). Solo el modelo control expone su resultado en el dashboard.

## Justificacion

El cliente exige esta capacidad para evaluar nuevas versiones del clasificador en condiciones de produccion real sin impacto operativo para los analistas.
